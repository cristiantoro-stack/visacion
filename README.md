# Visación · Telconsulting

Lanzador de la app de visación de facturas para el teléfono: <https://cristiantoro-stack.github.io/visacion/>

- **Android (Chrome):** "Instalar Visación" (o ⋮ → Instalar app).
- **iPhone (Safari):** Compartir → Agregar a pantalla de inicio → **apagar "Abrir como app web"** → Agregar.

Solo da el ícono y abre la app; no tiene datos ni claves. Entra solo quien tiene cuenta de telconsulting.cl activa en Visadores.
La fuente vive en el repositorio privado del flujo de caja (`visacion/telefono/`); este repositorio es solo lo publicado.
